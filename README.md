# 基于 MobileNetV2 的生活垃圾图像分类
深圳大学 · 人工智能课程实验项目

---

## 一、项目简介
本项目基于 PyTorch 深度学习框架，使用轻量级卷积神经网络 MobileNetV2，结合迁移学习方法，完成 **6 类生活垃圾图像分类**任务。
项目全程可在普通 CPU 环境下完成训练与推理，适合课程实验与小型识别场景。

---

## 二、数据集说明
本项目使用的数据集包含 6 类生活垃圾：
- `glass`（玻璃）
- `paper`（纸张）
- `cardboard`（纸板）
- `plastic`（塑料）
- `metal`（金属）
- `trash`（其他垃圾）

数据划分情况：
- 训练集：1768 张
- 验证集：328 张
- 测试集：431 张

---

## 三、上传文件说明

### 1. 代码文件
- `train.py`：模型训练脚本。
  负责加载数据集、构建 MobileNetV2 模型、执行训练流程，并在训练结束后自动保存最优权重。

- `infer.py`：单张图片推理脚本。
  加载训练好的模型，对输入图片进行预测，输出对应的垃圾类别。

### 2. 模型文件
- `best_garbage_model.pth`：训练后保存的最优模型权重文件。

### 3. 测试图片
- `奥利奥.jpg`：纸板类测试图片（奥利奥饼干盒）。
- `玻璃.jpg`：玻璃类测试图片（玻璃罐头瓶）。

### 4. 运行结果截图
- `infer_cardboard.jpg`：奥利奥图片推理的终端输出截图。
- `infer_glass.jpg`：玻璃图片推理的终端输出截图。

六、模型结构
主干网络：MobileNetV2（预训练权重冻结）
分类头：6 类全连接层
优化器：Adam，学习率 0.001
损失函数：交叉熵损失（CrossEntropyLoss）
七、实验结果
训练准确率：94%–98%
验证准确率：89%–92%
测试准确率：90%–93%
纸板、纸张、塑料的纹理特征清晰，识别精度最高；玻璃、金属因反光、透明特性导致特征相似，存在少量混淆，属于正常视觉误差。
八、测试示例
